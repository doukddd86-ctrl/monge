몽이 단어장 (PWA) 설치 방법

1. 이 폴더 안의 파일 전체를 무료 호스팅(GitHub Pages, Netlify 등)에 올려요.
   - index.html, manifest.webmanifest, sw.js, icons 폴더가 같은 위치에 있어야 해요.
   - 주소는 https:// 로 시작해야 설치가 돼요.
2. 휴대폰에서 그 주소를 열어요.
   - 안드로이드(크롬): 메뉴 > 앱 설치 또는 홈 화면에 추가
   - 아이폰(사파리): 공유 버튼 > 홈 화면에 추가
3. 처음 한 번은 인터넷에 연결된 상태로 열어야 오프라인 저장과 글꼴이 저장돼요.

업데이트할 때는 sw.js 맨 위의 monge-v1 을 monge-v2 처럼 바꿔서 같이 올리면 새 버전이 적용돼요.
진도는 기기 안에만 저장돼요. 단어장 화면의 '백업 저장'으로 가끔 파일을 만들어 두세요.
이전 이름(몽글)으로 설치한 앱은 같은 주소에 올리면 진도가 그대로 유지돼요.
